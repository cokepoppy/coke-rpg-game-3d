# 悬疑主线与地图 Boss 设计稿

## 目标

把移动浏览器版从“探索 + 零散战斗”推进到“收集线索 → 解谜验证 → 进入高难 Boss 战 → 获得下一段真相”的循环。当前只在本地 Chrome 调试，不涉及 VPS 发布。

## 核心谜题

主线暂名 **“断钟与失剑”**：沈临川醒来时佩剑失踪，苍山钟声在第七响前中断。客栈无名信、茶肆告示、月华药账和半枚青铜扣指向同一件事：有人在用“灯亭—药庐—寺后”的路线转移被调包的孩子，并故意把沈临川引到旧案现场。

线索不是一次性讲完，而是四段可回看的证据：

1. 客房木柜：取得 `unsigned_letter` 与 `copper_lantern_shard`。
2. 客房账册：只有拿到信后才能读出灯亭暗号，得到 `lantern_order_clue`。
3. 松风茶肆：把暗号与告示上的三行字对应，得到 `tea_house_cipher`。
4. 月华谷：药账与半枚青铜扣互相印证，得到 `moon_record_fragment`，开启月华谷 Boss。

每一段都写入 `storyFlags` 与 `storyLog`，并放入背包作为可见证据；重复进入不会重复发放物品或重复推进剧情。

## 当前移动端垂直切片

### 苍山旧道：引灯魇客

- 进入条件：取得无名信并解出客房账册暗号。
- 战场：寺院庭院复用现有 `battleTemple`。
- 外观：体型明显大于普通密探，披旧灯笼骨架与长斗篷；主色为暗金、墨黑、冷青火。
- 战斗：高气血、高防御，携带两名“残灯影卫”；半血后释放 `灯影回环`，优先压制低血量角色。
- 失败保护：失败不会消耗线索，玩家可以补给后重新挑战。
- 胜利：获得 `broken_sword_guard`，写入“有人故意拿走佩剑护手”的新证据，并开启月华谷的深层线索。

### 月华谷：照骨婆

- 进入条件：完成药账 / 青铜扣验证，并击败引灯魇客。
- 战场：复用现有 `battleBamboo`。
- 外观：药庐旧医师的异化形态，背后悬着裂镜与药囊；主色为月白、墨紫、毒绿，与引灯魇客明显区分。
- 战斗：高气血，携带一名“镜中侍”；拥有 `照骨针`、`裂镜回生`、`毒雾`，半血后改变技能优先级并提升伤害。
- 胜利：获得 `moon_record_fragment`，揭示“被调包的孩子不止一个”，并把故事推进到王府线。

## 实现边界

- Boss 配置与普通战斗配置分离，`BattleScene` 只接收一份 battle config，避免继续复制战斗逻辑。
- 角色资源仍遵循现有 4×4 方向帧、锚点审计和 `character-pack` 复制链路；生成源文件放在 `assets/characters/`，运行时文件由 `scripts/copy-wechat-assets.mjs` 生成。
- 先接入苍山旧道与月华谷两个 Boss，先跑静态检查、资源复制、Chrome battle E2E，再考虑更多地图。
- 不修改 VPS、不改公共部署、不改变现有普通密探通关条件。
